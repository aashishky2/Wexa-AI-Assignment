Architecture

How it works

A deterministic, mathematically proven workflow ensuring your enterprise AI never sees data it shouldn't.

01

Agent Passport Minting

Before an autonomous AI worker begins a task, it requests an ephemeral Passport from the Agent OS. The passport cryptographically binds the agent's identity to a strict, time-bound scope.

02

Graph ReBAC Traversal

The backend executes a highly optimized Cypher traversal against your Neo4j Knowledge Graph to mathematically calculate relationship paths between the Agent and all relevant Data Assets.

03

Zero-Trust Context Pruning

Any data node without a direct, mathematically proven relationship path to the agent's passport is aggressively pruned from the RAG context. The entire access decision is recorded as an immutable Audit Log.

04

Secure LLM Execution

The pruned, verified context is forwarded to the LLM (OpenAI, Anthropic). The AI generates an answer strictly grounded in data it is proven to have access to, eliminating data leaks.

Developer Guidelines

How to Secure Your LLM in 3 Steps

Stop data leaks in your AI apps instantly. Follow this integration flow to replace flat RBAC with SentinelGraph ReBAC.

01

Model Identity & Resource Topologies

Represent contributors, organizations, projects, agents, and sensitive assets as connected nodes so access can be proven through relationship paths.

(:Contributor)-[:WORKS_AT]->(:Organization)
(:Contributor)-[:CONTRIBUTED_TO]->(:Project)
(:Project)-[:HAS_ACCESS_TO]->(:DataAsset)
(:Agent)-[:PERMITTED_SCOPE]->(:DataAsset)
02

Wrap your RAG Retrieval Logic

Before feeding vector search results to the LLM context window, pass the retrieved asset IDs to the SentinelGraph API. It runs a sub-millisecond Cypher shortest-path traversal to verify the user has a mathematical relationship path to the data.

# Python Example with LangChain
retrieved_docs = vector_store.similarity_search(query)

# SentinelGraph instantly prunes unauthorized docs
secure_docs = sentinelgraph.prune_context(
    user_id=current_user.id,
    documents=retrieved_docs
)

llm.generate(prompt, context=secure_docs)
03

Monitor Live Supply-Chain Risks in the Dashboard

Once deployed, open your SentinelGraph Dashboard to view real-time SOC2 audit logs. You can visually explore the graph to identify transitive data leaks, such as when two competing organizations share a contributor on a critical dependency layer.
